## 1-1. 生成AI/LLMの普及と現状

### 生成AIの急速な普及

**生成AIとは？**

生成AIとは、ユーザーの指示に応じてテキスト、画像、音声などのコンテンツを生成できるAI技術の総称です。質問に答える、文章を作成する、コードを書く、画像を生成するなど、様々なタスクをこなすことができます。

**LLMとは？**

LLM（Large Language Model：大規模言語モデル）は、生成AIの一種で、特に自然言語処理に特化したAIモデルです。膨大なテキストデータで学習することで、人間のような自然な文章の理解・生成を実現しています。このLLM技術を基盤とした生成AIサービスが、近年急速に普及しています。

**主要な生成AI**

2022年11月にChatGPTが公開されて以来、生成AI技術は急速に進化し、私たちの生活や業務に浸透してきました。現在では、以下のような生成AIが広く利用されています。

- **ChatGPT**（OpenAI）
- **Claude**（Anthropic）
- **Gemini**（Google）
- **Copilot**（Microsoft）

これらのサービスは、2022年末から2026年現在まで、わずか3年余りの間に劇的な進化を遂げています。初期のシンプルなチャットボットから、複雑な推論や長文の理解、マルチモーダル対応（テキスト・画像・音声）へと機能が拡張されてきました。

### 企業における生成AI活用の現状

企業での生成AI活用も急速に広がっています。主な活用場面は以下のとおりです。

- **情報検索や要約作業の効率化**
  - 社内文書の検索・要約
  - 議事録の自動生成
  - メールやレポートの下書き作成

- **コーディング支援での活用**
  - GitHub Copilotによるコード補完
  - バグの発見や修正提案
  - コードレビューの支援

- **業務プロセスの自動化・効率化**
  - データ分析の自動化
  - カスタマーサポートの支援
  - 定型業務の効率化

多くの企業が、これらの技術を活用することで業務の生産性向上を実現しています。

## 1-2. AIエージェントとは

### AIエージェントの定義

AIエージェントとは、**自律的にタスクを実行するAIシステム**のことです。従来のチャットボットとは異なり、ユーザーの指示を理解し、複数のステップを経て目標を達成することができます。

**生成AI/LLMとの違い**

| 生成AI/LLM | AIエージェント |
|---|---|
| 入力に対してテキストを生成・返答する | 指示を解釈し、自律的に行動する |
| 1回の指示に対して1回の応答 | 複数のステップを経て目標を達成する |
| 次に何をするかはユーザーが決める | 次に何をすべきかを自ら判断する |
| 基本的に外部システムへのアクセスはしない | ツールや外部システムと連携して実行する |

### AIエージェントの具体例

現在、以下のようなAIエージェントが実用化されています。

**Claude Desktop**
- ファイル操作やWebアクセスを伴う複雑なタスクを実行
- 「この資料を要約してPDFにして」といった一連の作業を自動化

**VS Code + GitHub Copilot（Agentモード）**
- コード生成だけでなく、プロジェクト全体の理解と編集が可能
- 「このバグを修正して」と指示すると、関連ファイルを確認して修正案を提示

これらのAIエージェントは、単なる質問応答ではなく、**複数のツールを組み合わせて目標を達成する**という点が特徴です。

## 1-3. MCPの必要性

AIエージェントをより実用的にするには、外部システム（データベース、WebAPI、ファイルシステムなど）との連携が不可欠です。

この連携をしやすくした仕組みが、**MCP（Model Context Protocol）** です。<br>MCPを使うことで、AIエージェントが統一された方法で外部システムにアクセスできるようになります。
